Lina Theme Documentation & Guide

Official merchant documentation for Lina Theme—a high-performance, modern Shopify theme custom-built for electronics, gadgets, and tech stores.

Theme Overview

Lina Theme is engineered for high-speed performance, clean aesthetic appeal, and maximum conversion rates. Built with Shopify Online Store 2.0 standards, Lina provides over 45 customizable sections, dark mode capabilities, slide-out drawer cart with free shipping goals, and full Google JSON-LD schema out of the box.

Theme Installation (Shopify Theme Store)

Lina Theme is distributed directly through the official Shopify Theme Store. Installing and testing Lina in your store requires no upfront payment:

  1. Go to the official Shopify Theme Store and search for Lina Theme.
  2. Click Try theme to test Lina with your actual store products and catalog.
  3. Shopify will automatically add Lina to your Shopify Admin > Online Store > Themes library as an unpublished draft.
  4. Click Customize next to Lina Theme to build your layouts, set color schemes, and configure sections.
  5. When ready to go live, click Publish (or Buy theme) to make Lina your active online store theme.

Free Unlimited Trial: You can test and customize Lina Theme with your products and content for as long as you need for free. You are only charged when you publish Lina to your live domain.

Global Theme Settings

Access these settings in the Shopify Theme Editor under Theme Settings (Gear Icon) > Global.

Setting Name Control Type Description & Options
Button Border Radius Range Slider (0 - 40px) Controls global corner roundness for primary and secondary call-to-action buttons.
Image Border Radius Range Slider (0 - 40px) Sets corner rounding for banner images, gallery tiles, and product feature media.
Card Border Radius Range Slider (0 - 40px) Sets corner rounding for product cards, collection cards, and blog showcase tiles.

Logo & Favicon Settings

Located under Theme Settings > Logo & Favicon.

Setting Name Type Description
Desktop Logo Image Picker Primary logo displayed on desktop headers. Falls back to Shopify Admin Brand Logo if empty.
Desktop Logo Width Range (30 - 350px) Controls custom logo display width on desktop screens.
Mobile Logo Image Picker Optional dedicated logo image for mobile screens. If left blank, automatically uses Desktop Logo.
Mobile Logo Width Range (20 - 250px) Controls custom logo display width on mobile devices.
Favicon Image Image Picker Displayed in web browser tabs (automatically scaled to 32x32px).

Color Schemes & Dark Mode Engine

Located under Theme Settings > Color Schemes. Lina uses a color scheme engine allowing you to create unlimited color palettes for your store sections.

Color Token Applied UI Elements
Background Section background color (supports solid hex colors).
Background Gradient Optional background gradient for high-impact hero and banner sections.
Body Text Color Primary paragraph text, specs list, and body copy.
Heading Color Section titles (H1, H2, H3), card headings, and price text.
Button Background Primary action buttons, badge background, and primary highlights.
Button Text Color Label text inside primary buttons and CTA badges.
Border Color Subtle card dividers, input field borders, and tab separators.

Typography & Font Controls

Located under Theme Settings > Typography. Customize font families, font scale, line heights, and individual heading levels (H1 to H5).

Setting Options / Range Description
Body Font Family Shopify Font Picker Controls primary body text font (e.g., Assistant, Inter, Roboto, System Stack).
Body Font Scale 80% – 130% Global font scaling multiplier for all body text.
Body Line Height 1.2, 1.4, 1.5, 1.6, 1.8 Line spacing for body paragraphs.
Heading Font Family Shopify Font Picker Controls font family for all section headings and titles.
Heading Text Transform None, UPPERCASE, lowercase, Capitalize Text case transformation for headings.
Heading Letter Spacing -1px to 8px Letter spacing (kerning) for section titles.
H1, H2, H3, H4, H5 Sizes Custom Pixel Sliders Independent font size and font weight controls for H1 through H5.

Product Cards Customization

Located under Theme Settings > Product Cards. Configure product grid card appearance globally across collection pages and product sliders.

Setting Name Description
Card Image Fit Mode Switch between Cover (crops to fill container) or Contain (shows complete image without cropping).
Show Secondary Image on Hover Flips to the 2nd product image when hovering over product cards.
Show Color Swatches Displays interactive variant color swatches on product grid cards.
Show Vendor Displays product brand or vendor name above title.
Show Badges & Position Renders Sale and Sold Out badges in Top Left, Top Right, Bottom Left, or Bottom Right corner.
Add to Cart Button Options Configure button size, width (30%-100%), and optional Shopping Bag or Plus icon.

Built-in SEO & Google JSON-LD Schema

Lina includes native Google Rich Snippet support in snippets/json-ld.liquid without requiring paid SEO apps.

Schema Type Supported Microdata Google SERP Result
Product Name, Price, Currency, SKU, Barcode/GTIN, Availability, Brand, Image, Condition Renders price, stock status, and product star ratings in Google Search.
FAQPage Questions & Answers from FAQ Accordion section Renders expandable FAQ drop-down boxes directly on Google search results.
BreadcrumbList Home > Collection > Product path Displays clean URL breadcrumb navigation paths in search engine listings.
Organization & WebSite Store Name, Logo URL, SearchAction target Powers Google Knowledge Graph brand cards and Sitelinks Search Box.
